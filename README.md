# MCPD DISPATCH TERMINAL

Welcome to the **MCPD DISPATCH TERMINAL**. 

This project is a terminal style simulation of the Main City Police Department (MCPD), a highly fictionalized, dystopian, and incredibly trigger-happy police force. 

For more detailed information and lore about the MCPD universe, please visit this link:
[MCPD Lore & Information](https://notebook.google.com/notebook/64b934e5-bbc4-4658-8f94-57d2184adaf2)

## Features & How It Works

The MCPD DISPATCH TERMINAL runs entirely in your browser and simulates a live, chaotic police dispatch radio channel. You act as the centralized dispatcher for the city, attempting to maintain order while managing a force of sociopathic officers.

### Core Simulation Mechanics
- **Live Radio Chatter:** Watch as exactly 58 active duty officers patrol the city. Officers will automatically respond to dispatch calls, request backup, and chat over the radio.
- **Meritocratic Ranking System:** A strict 11-tier ranking system based entirely on lifetime kills. All new recruits start with **0 kills (Private)** and must earn their blood on the streets to climb all the way to Chief (which requires 200 Sextillion kills).
- **Department Omni-Tracker:** A live, collapsible statistics dashboard that tracks the department's operating budget, total kills, total arrests, and incidents of unauthorized deadly force in real-time.
- **Code 5 SWAT Integration:** Trigger a massive tactical response with the push of a button. SWAT deployment instantly pacifies all active panics with extreme prejudice. Pinned-down patrol officers also have a chance to scream for SWAT backup over the radio.
- **Dynamic Personalities & Reports:** Every officer has a unique psychological profile (Aggressive, Corrupt, Rookie, Veteran, etc.). This dictates how they resolve crimes. They file dynamic incident reports complete with direct quotes justifying their actions (e.g., admitting to taking bribes or accidentally using excessive force).

### Terminal Interface & Tools
- **Collapsible Control Panels:** Keep your workspace clean. The Department Stats, Critical Emergencies, and Advanced Configuration menus are all tucked into collapsible dropdown panels to prevent accidental deployments.
- **Citizen Database & Wanted Stars:** A searchable roster of 1,000 indexed citizens. You can view their dossiers and manually click their **GTA-Style Threat Level Stars (1-6)**. Giving them stars automatically declares them Wanted and assigns a massive bounty.
- **Dispatch Input:** Type commands into the bottom input field to communicate with the units. Officers will dynamically reply based on what you say (and will make fun of you if you type gibberish).
- **10-99 Panics:** If an officer gets into a massive firefight or you trigger a manual panic, a realistic siren will blare and the terminal will flash red until the panic is manually cleared or SWAT is deployed.
- **Recruitment:** Use the **JOIN MCPD** tab to dynamically generate new civilian applicants and forcefully recruit them into the force.

## Usage

Simply open MCPD_DISPATCH_TERMINAL.html in any modern web browser to start the simulation. 
No build steps or server environments required.
