# MCPD Dispatch Terminal

Welcome to the **MCPD Dispatch Terminal**. 

This project is a terminal-style simulation of the Main City Police Department (MCPD) — a highly fictionalized, dystopian, and incredibly trigger-happy police force. 

For more detailed information and lore about the MCPD universe, please visit this link:
[MCPD Lore & Information](https://notebook.google.com/notebook/64b934e5-bbc4-4658-8f94-57d2184adaf2)

## Features & How It Works

The MCPD Dispatch Terminal runs entirely in your browser and simulates a live, chaotic police dispatch radio channel. 

- **Live Radio Chatter:** Watch as exactly 58 active-duty officers patrol the city. Officers will automatically respond to dispatch calls, request backup, and occasionally start slacking off and telling terrible cop jokes over the radio.
- **Dynamic Personalities:** Every officer has a unique psychological profile (Aggressive, Rookie, Veteran, Lazy, etc.). Their personality heavily dictates how they respond to crimes and interact with each other.
- **Automated Crime Events:** New civilian reports or crime events will flash across the terminal regularly. These range from standard traffic accidents to massive shootout sequences and temporal anomalies.
- **Event Resolutions:** Officers will dynamically file formal incident reports in the **IMPORTANT LOGS** tab based on how they handled a crime. Expect heavy casualties, as the MCPD's motto is *"Protect and kill."*
- **Dispatch Input:** You act as the dispatcher. You can type commands into the bottom input field to communicate with the units. Be careful—if you type gibberish or nonsense, the officers will call you out for having a stroke.
- **10-99 Panics:** If an officer gets into a massive firefight or you trigger a manual panic, a realistic siren will blare and the terminal will flash red until the panic is manually cleared.
- **Recruitment:** Use the **JOIN MCPD** tab to dynamically generate new civilian applicants and forcefully recruit them into the Main City Police Department.

## Usage

Simply open index.html in any modern web browser to start the simulation.
