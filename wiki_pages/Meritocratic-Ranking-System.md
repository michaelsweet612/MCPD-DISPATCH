# Meritocratic Ranking System

Unlike soft, traditional police departments, the MCPD does not promote based on tests, leadership, or time served. We promote based on **results**. Specifically, lifetime pacifications (kills).

All officers are instantiated as **Privates** with 0 kills. As they violently resolve crimes, they climb the following 11-tier ladder:

| Rank | Abbreviation | Kills Required |
|------|--------------|----------------|
| Private | PVT | 0 |
| Corporal | CPL | 250,000 |
| Sergeant | SGT | 1,000,000 |
| Staff Surgeon | SSG | 5,000,000 |
| Sergeant First Class | SFC | 8,000,000 |
| First Sergeant | 1SG | 9,000,000 |
| Sergeant Major | SGM | 10,000,000 |
| Command Sergeant Major | CSM | 35,000,000 |
| Sergeant Major of the Police | SMP | 3,000,000,000 |
| General of the Police | GEN | 80,000,000,000,000,000,000 |
| Chief | CHIEF | 200,000,000,000,000,000,000 |

*Note: Achieving the rank of Chief automatically makes you the most aggressive officer in the precinct.*
